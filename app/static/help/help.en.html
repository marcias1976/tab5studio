Tab5 Studio

An editor for designing the look of the M5Stack Tab5: clock themes, the intro, the alarm screen and the timer. You flash the program to the Tab5 once, then save the project on the Tab5 with one click, without building. The Tab5 web page, Wi-Fi, alarms, timer and settings are in every build.

Author: Jakub W. · MARCIASMEDIA

1Design

Add elements and arrange them on the 1280×720 display.

2Check

Preview in Studio or live on the Tab5, without building.

3Save to the Tab5

Preview → Save to the Tab5 for good. The Tab5 shows the project after every start.

4Build

Only for the first flash (USB) and program updates (Wi-Fi).

Workspace

  1. Studio language — PL / EN. Changes the editor texts only, not the project.
  2. Project — name, New, Open, Save; next to it Undo and Redo. “Save” asks: overwrite the saved project or save it as a new one (an existing name asks before overwriting). Ctrl/Cmd + S saves the current project right away. After a page reload Studio opens the last project and brings back unsaved changes from the browser. In the “Open” dialog, Export downloads the project with its images and fonts as a .zip (a backup, or to move it to another server), and Import… loads such a file.
  3. Screens — Theme-1, Theme-2, Theme-3 (optional), Intro, Alarm, Timer. Each one is designed separately.
  4. Library — saved versions of the current screen.
  5. Add element — a click puts the element in the middle of the screen. The list depends on the screen (e.g. “Alarm name” only on the Alarm screen).
  6. Layers — the elements of the screen. Higher = in front. Drag to reorder; double-click renames; the eye hides, the lock stops it from moving, the bin deletes (Ctrl+Z undoes).
  7. Tab5 menu — on the clock themes the top right corner (the “MENU” frame) holds the device's menu button. It is always on top, so keep important elements out of it.
  8. Tab5 timer — the top left corner (the “TIMER” frame) holds the pill with the time left while the timer counts in the background. Want it elsewhere? Add a Timer element and place it anywhere: on that theme it replaces the pill and the corner stays free. In the preview the timer simulation button shows the pill as on the Tab5.
  9. Display — drag elements; the handles resize them.
  10. Properties — settings of the selected element or, with nothing selected, of the whole screen (background, palette, duration).
  11. Bottom panel — Assets (images and fonts) and Build. The handle on the top edge changes its height, the arrow on the right collapses it.
  12. Zoom — − / + and fit to the window.
  13. Help — this guide (? or F1 key).
  14. Preview — in Studio or on the Tab5; here are also saving to the Tab5, the screenshot, settings backups and the Tab5 connection.
  15. Sign out (the door icon at the end of the header) — shown when Studio has a password; it takes you back to the sign-in page.

“Auto” colours and the palette

With nothing selected, the Properties panel shows the screen palette: the clock digit colour and the value colour. An element with “auto” ticked takes its colour from the palette. On the Tab5 you can change the palette later on the web page (colours and colour presets) — all “auto” elements follow. Elements with their own colour stay as they are.

Common properties

  • Name — how the element is called in the layers.
  • X, Y, W, H — position and size in Tab5 screen pixels.
  • Opacity — transparency of the element.
  • Arrange — center horizontally / vertically, to front, to back, duplicate, delete.

Grouping

  • Shift / Cmd + click — adds an element to the selection; Ctrl/Cmd + A — all visible ones.
  • Ctrl/Cmd + G groups, Ctrl/Cmd + Shift + G ungroups. A click on a grouped element selects the whole group; double-click or a click in the layers — one element of the group.
  • A group moves and scales together (e.g. an icon with its sensor value).
  • For several elements the Properties panel shows alignment: left, right, top, bottom, and centers horizontally and vertically.
  • Guide lines snap to the edges and centers of other elements and of the screen. Hold Shift while dragging to turn snapping off.

Intro

The intro shows after the Tab5 starts and after “Show intro” on the web page. The built-in look (MARCIASMEDIA logo with a bar) is ticked by default. Untick it to design your own:

  • Duration — how long the intro stays on screen.
  • The “Bar” loader fills exactly over that time; other loaders loop.
  • “Preview → On the Tab5” on this screen plays the intro on the device right away.

Alarm and Timer

The Alarm screen shows when an alarm rings or the timer ends. The Timer opens when you hold a finger on the clock. Both have a built-in look; untick “Built-in look” to get a draft to rework.

Tap actions

Any element (image, shape, text, icon) can be a button. Choose the action in the On tap section:

  • Alarm: Snooze, Stop.
  • Timer: Start/Pause, Reset, +1 min, −1 min, +5 s, −5 s, Set time (e.g. 10 min), Close.

In a group, set the action on the elements that should react (double-click selects one element of a group).

The Alarm name, Timer time and Start/Pause elements show the current content from the Tab5.

Library and projects

  • The Library keeps many versions of each kind of screen: clocks (they fit Theme-1 and Theme-2), intros, alarms and timers.
  • Save — type a name and save the current screen. Saving under an existing name asks before overwriting.
  • Each entry has: Load (for clocks: into Theme-1 or Theme-2), rename, delete. The thumbnail shows the look.
  • A project (New / Open / Save at the top) is the whole set: the clock themes, intro, alarm, timer and palette — what you send to the Tab5. “New” gives an empty project.

Example: the Library holds five clocks. For the “Winter” project you load “Big LED” as Theme-1 and “Analog” as Theme-2, save the project, then Preview → Save to the Tab5 for good.

Assets: images and fonts

  • Images — Upload PNG, JPG, WebP or SVG. A click on a thumbnail puts the image on the screen. Only images used in the project go into the build.
  • Fonts — built-in (Inter, Orbitron, Roboto Mono, Bebas Neue, Oswald, Rajdhani Bold) and your own TTF/OTF files, marked ★. A font shows Polish characters if the file has them.

Preview

  • In Studio (P key) — the screen alone, with a ticking clock and animations. − / + zooms (50% to 100%; 100% by default, less only in a small window). “Alarm on” and “Timer running” show the alarm and timer badges (or the timer pill in the corner) as on the Tab5, Esc closes.
  • On the Tab5 — sends the project to the device without building. The Tab5 shows it until the preview is closed or the device restarts; this preview is not stored (that is what “Save to the Tab5 for good” is for). On the Alarm and Timer screens the Tab5 opens that screen right away.
  • Tab5 connection — address (e.g. 192.168.1.50 or tab5.local) and the web page PIN. “Test connection” shows whether the Tab5 answers.
  • Tab5 connection also shows the program version on the Tab5 (the date and time of its build).
  • While a preview is on the Tab5, the Preview button is yellow. “On the Tab5” sends the changes again, and Close the preview on the Tab5 in that menu ends it: the Tab5 goes back to the saved project (or to the look of its program).

Save to the Tab5 for good

  • Save to the Tab5 for good — the Tab5 saves the project and shows it after every start. No building or flashing: you build only to update the program itself. The project palette (the “auto” colors) goes to the Tab5 settings too, so the colors match Studio; you can change them later on the Tab5 web page or in its menu.
  • The project goes to the Tab5 memory (about 3.3 MB, or about 6.8 MB after one USB flash of this or a newer version; no SD card needed). A usual clock takes 0.2–0.5 MB; only full-screen images take a lot (about 1.8 MB each). The dialog shows the project size and the free space. The Tab5 keeps one saved project: every save replaces the previous one.
  • A saved project uses “auto” colors like a program: the palette and color presets from the Tab5 web page still apply.
  • Theme-3: the tab next to Theme-2, switched on with “Use Theme-3” (it also switches on when you add its first element). A swipe then switches 1 → 2 → 3 on the Tab5; you can also pick it on the web page and in the Tab5 settings. It works in the preview and in the saved project, not in a compiled program. The Tab5 builds it only while it is shown, so it takes no memory. “Insert the weather for a week” (with nothing selected) inserts a ready weather screen: place, date, time, the weather now and 7 days from today; the first day reads “Today”. The “Original Project” Studio saves on its first start, and every new project, has the same screen.
  • Under Restore the program's look Studio shows which project is saved on the Tab5 and whether it matches the open one (“same as the open one” / “the open one has changes”). This button deletes the saved project from the Tab5.
  • When the saved project ends in a restart three starts in a row, the Tab5 skips it and starts with the look of its program. Studio then shows a message; save the project again or delete it.
  • A Tab5 with an older program that cannot save projects needs the full web-install.bin over USB once. It erases the Tab5 settings; the Wi-Fi from the .env file is in the program.

Building and flashing

  1. Save the project (the current state of the editor is built).
  2. Choose the Tab5 start language (you can change it later in the Tab5 settings or on the web page).
  3. Optionally type a new 4-digit web page PIN. Empty = the PIN from the server settings. The PIN is not stored anywhere.
  4. Optionally type a Note (e.g. “bigger clock”): it shows in the build list and on the Tab5 in Menu → Other → Program version. The program version is the date and time of the build.
  5. Click Build .bin or Build and send — the second one sends the program to the Tab5 right after the build. The first build takes a few minutes, later ones about a minute. The log shows progress.
  6. Next to a build in Previous builds: On the Tab5 sends the program over Wi-Fi, the arrow downloads web-install.bin. The build running on the Tab5 now has a green field. Studio keeps the 10 newest builds (and the one on the Tab5) and deletes older ones by itself.

Tab5 settings backups

  • Preview → Tab5 settings backups… — a copy of the Tab5 settings, color presets and alarms, and of the project saved from Studio. Studio makes one by itself before every program update; “Back up now” makes one right away. The 20 newest backups are kept.
  • Restore writes the backup to the Tab5 (it restarts), then Studio saves the project from the backup on it. Handy after a USB flash, which erases the settings. Wi-Fi passwords are not copied.
  • Preview → Tab5 screenshot shows what the Tab5 displays right now.
  • When the Tab5 is low on memory, or restarted after an error or a freeze, Studio shows a warning. The details are on the Tab5 web page, “Technical state” card.

Flashing with ESP Web Tool (Chrome / Edge)

  1. Connect the Tab5 to the computer with a USB-C cable.
  2. Open espressif.github.io/esptool-js, click Connect and choose the Tab5 port.
  3. Type the address from the table in Flash Address, choose the file and click Program.
  4. When it finishes, press the reset button on the Tab5 or unplug and plug the cable.

You can download a copy of the program now on the Tab5 from its web page, System tab → “Program backup” — so you can always go back to the previous version.

Problems and questions

“On the Tab5” says the Tab5 does not answer
Check the address and PIN in “Tab5 connection”. The Studio server must be in the same network as the Tab5. A fixed IP for the Tab5 in your router helps.
The Tab5 says it has no live preview
The Tab5 runs an older program. Flash a new build once — then the preview works.
The build fails
The last lines of the log say what happened. Most often it is a lack of space (very large images) or no internet connection on the first build.
Colours on the Tab5 differ from Studio
“Auto” elements take the palette colour, which can be changed on the Tab5 web page. Give an element its own colour if it must not change.
Where are my projects?
On the server, in the data/ folder (projects, library, assets, builds). Back up this folder so nothing gets lost.
