Tab5 web page

Every Tab5 has its own page for control from a phone or computer. Five tabs: Home (preview and quick actions), Look, Alarm clock, Schedule and System. The page works in the same Wi-Fi network as the Tab5, without internet and without an account.

Opening the page

  1. Type http://tab5.local or the Tab5 IP address in the browser. The IP is shown on the Tab5: menu icon in the top right corner of the clock → “Wi-Fi” tab.
  2. Enter the 4-digit PIN (set when building in Studio). After the fourth digit the page opens and remembers the PIN on this device.
  3. Wrong PIN — the fields blink red. After 5 wrong tries within 5 minutes you have to wait 30 seconds.
  4. On a phone, add the page to the home screen (Safari: Share → “Add to Home Screen”; Chrome: menu → “Add to Home screen”). It then opens like an app.

If tab5.local does not work (e.g. on some Android phones), use the IP address. A fixed address for the Tab5 in your router helps.

Page layout

  • Tabs — Home, Look, Alarm clock, Schedule, System. The page remembers the last tab; a tab's address (e.g. #sys) can be bookmarked.
  • Status dot — green: the Tab5 answers. Red: the phone can't see the Tab5 (another network, the Tab5 is off or starting).
  • PL / EN — the page language on this device. The Tab5's own language is in the System tab.
  • Refresh — gets the current state and the screen preview. The page does not refresh by itself, to spare the Tab5.
  • Log out — the page forgets the PIN on this device (on a phone: just the icon in the header).
  • While an alarm rings, a bar with Snooze and Stop appears above the tabs.

Home

  • Preview — a picture of what the Tab5 screen shows now.
  • Theme-1 / 2 / 3 and Light / Dark — the clock theme and the mode (Theme-3 when the design has one).
  • On / Off switches the screen right away, Show intro, Brightness in light mode: Min or Max (set it exactly in the settings on the Tab5).
  • Now — temperature, humidity and pressure from Open-Meteo (every 10 minutes), the place, Wi-Fi with signal quality, time since start, Last start (why the Tab5 started) and Program version — the date of the Studio build and its note.

When the screen is off, a touch lights it for a minute.

Look

  • Digit color and Sensor value color — ready colors or any color (the rainbow circle); values can be “Like digits”.
  • Color presets — up to 8 tiles with a color preview; “day” / “night” marks a preset applied with the mode. A click applies one (the active one has a yellow frame), the pencil renames it, the bin deletes it, “Save current colors” saves a new one or overwrites a chosen one.
  • Theme at start, Theme rotation (switching by itself while nobody touches the screen) and Theme at night (during night-mode hours; in the morning the start theme comes back).
  • Colors in light / dark mode — a preset applied together with the mode.

The colors apply to elements with the “auto” color in the Studio design.

Alarm clock

  • + Add alarm — up to 10 alarms. Changes are saved by themselves.
  • Each alarm: time, name (shown on the ringing screen), switch and bin.
  • Weekdays — when it rings. Once — a single time, then the alarm turns itself off.
  • Volume and Listen — the beep plays for 8 seconds; meanwhile the button turns into Stop.
  • Snooze — after how many minutes the alarm rings again; Timer snooze — a separate time for the timer.

On the Tab5

A ringing alarm shows the time, the name and the Snooze and Stop buttons. With no reaction it stops by itself after 10 minutes. You can design this screen in Studio (the Alarm tab).

Schedule

  • Night mode — from when to when the clock is dark (23:00–5:40 by default). A manual mode change lasts until the next of these times.
  • Screen off schedule — hours when the screen is completely off.

System

Device

  • Place for the weather — a name (any country) or a Polish postcode. Click Search and pick from the list; the weather refreshes right away.
  • Device language — Polish or English (Tab5 menu, dates, buttons); the Tab5 restarts.
  • Restart — the Tab5 starts again (about 10 seconds). Settings are kept.

Technical state

  • Program version, program slot, free memory (green, amber below 60 KB, red below 30 KB), the last crash and screen freezes.
  • Memory after each start step — how much memory is left after each part of the start.

Program backup

  • Program (app.bin) — the program only. Full installer (web-install.bin) — everything from scratch, at 0x0.
  • The backup has no settings or Wi-Fi passwords. Settings and alarms are copied by Studio (Preview → Tab5 settings backups).

SD card

  • Card model and free space. Format erases the whole card (after a confirmation).
  • The “Card / Folder / …” bar — click a name to go up. The folder icon with a plus — new folder. Upload — several files at once, with a progress bar.
  • Next to files: the arrow downloads, the bin deletes (a folder with its contents).

On the Tab5 itself

Timer

  • Tap the minutes or seconds and change them with − / + (holding changes faster).
  • 5 / 10 / 15 min — quick setting. Start / Pause, Reset.
  • A new timer starts at 00:00. Back returns to the clock; the timer keeps counting and an icon with the time left shows in the corner — a tap opens the timer.
  • When time is up, a sound rings. Snooze counts the “Timer snooze” time again.

Settings on the Tab5

The menu icon opens the settings, shared with the web page — a change in one place shows in the other. Six tabs: Wi-Fi (networks), Weather (place), Clock, Screen, Alarms and Other. The big Back button returns to the clock. Color presets and alarm names and volume are set on the web page only.

The device screens above are shown in Polish; with the device language set to English they show English texts.

Problems and questions

The page does not open
The phone must be in the same Wi-Fi network as the Tab5. Use the IP address instead of tab5.local. Right after power-on the Tab5 needs about 10 seconds to join Wi-Fi.
I forgot the PIN
The PIN is set when building in Studio. Build with a new PIN and send it with “On Tab5” (or flash app.bin) — the settings are kept.
No weather shown
The Tab5 needs internet. Check the place in the System tab.
The Tab5 restarts by itself
See “Last start” on Home and “Technical state” in the System tab. “Brownout” usually means a weak power supply or cable.
Page colours do not change my design
Page colours only change elements with the “auto” colour. Elements with their own colour are set in Studio.
